ЗАПУСК ПАЙПЛАЙНОВ

Перед первым запуском:
  - скачан aws-java-sdk-bundle-1.12.526.jar в spark/jars/ (см. Training_instruction.md)
  - создан .env (cp .env.example .env) и заполнены SUPERSET_SECRET_KEY и AIRFLOW_FERNET_KEY
  - Git Bash на Windows: выполни один раз
      echo 'export MSYS_NO_PATHCONV=1' >> ~/.bashrc
    и открой терминал заново. Иначе Git Bash искажает пути вида /home/jovyan/...
    (ошибки "No such file" или "No FileSystem for scheme D").

Все команды выполняются в корневой папке проекта (там, где docker-compose.yml).
Spark сам подхватывает JAR-файлы и настройки MinIO из образа, поэтому --jars и --conf не нужны.
Spark работает в local mode внутри контейнера spark; UI запущенного job'а — http://localhost:4040
(второй одновременный job — 4041).

ВЕТКА 1. ПАКЕТНАЯ ЗАГРУЗКА (Postgres -> MinIO -> ClickHouse)

Шаг 0. Подними ядро стека:
  docker compose up -d

Шаг 1. Создай таблицу в Postgres и добавь строки:
  docker exec postgres-src psql -U postgres -d mydb -c "CREATE TABLE IF NOT EXISTS orders (id SERIAL PRIMARY KEY, name VARCHAR(50), amount FLOAT);"
  docker exec postgres-src psql -U postgres -d mydb -c "INSERT INTO orders (name, amount) VALUES ('test', 100.5), ('test2', 200);"

Шаг 2. Postgres -> MinIO (полный снимок таблицы в s3a://bucket/batch_output):
  docker exec spark spark-submit /home/jovyan/scripts/pg_to_minio.py

Шаг 3. MinIO -> ClickHouse (полный снимок: TRUNCATE + INSERT в orders_batch, повторный запуск не создаёт дублей):
  docker exec spark spark-submit /home/jovyan/scripts/minio_to_clickhouse.py

Шаг 4. Проверка:
  docker exec clickhouse clickhouse-client -q "SELECT * FROM orders_batch ORDER BY id"

ВЕТКА 2. STREAMING / CDC (Postgres -> Debezium -> Kafka -> MinIO -> ClickHouse)

Шаг 0. Подними ядро + стриминг:
  docker compose --profile streaming up -d
  Таблица orders должна существовать (ветка 1, шаг 1).

Шаг 1. Зарегистрируй Debezium-коннектор (подробнее — "регистрация debezium connector'а.txt"):
  curl -X POST -H "Content-Type: application/json" --data @pg-connector.json http://localhost:8083/connectors/
  curl http://localhost:8083/connectors/pg-connector/status
  Ожидается "RUNNING" у connector и у tasks. Топик pg.public.orders Debezium создаст сам.
  Если коннектор уже зарегистрирован, POST вернёт 409 Conflict — это нормально, сразу проверяй status.

Шаг 2. Запусти стрим Kafka -> MinIO в ОТДЕЛЬНОМ терминале (работает бесконечно, остановка — Ctrl+C):
  docker exec spark spark-submit /home/jovyan/scripts/kafka_to_minio.py
  Checkpoint хранится в s3a://bucket/checkpoints/kafka_orders, после перезапуска стрим продолжит с того же места.

Шаг 3. Поменяй данные в Postgres:
  docker exec postgres-src psql -U postgres -d mydb -c "INSERT INTO orders (name, amount) VALUES ('cdc_test', 777);"
  docker exec postgres-src psql -U postgres -d mydb -c "UPDATE orders SET amount = 999 WHERE name = 'test';"
  docker exec postgres-src psql -U postgres -d mydb -c "DELETE FROM orders WHERE name = 'test2';"

Шаг 4. Через 15-20 секунд останови стрим (Ctrl+C) — при 8 ГБ RAM два Spark-драйвера одновременно не помещаются.

Шаг 5. MinIO -> ClickHouse (разбор JSON, дедупликация через ReplacingMergeTree):
  docker exec spark spark-submit /home/jovyan/scripts/minio_to_clickhouse_kafka.py

Шаг 6. Проверка:
  все события CDC:   docker exec clickhouse clickhouse-client -q "SELECT * FROM orders_cdc ORDER BY id, version"
  текущее состояние: docker exec clickhouse clickhouse-client -q "SELECT * FROM orders_current ORDER BY id"
  В orders_current должны быть те же строки, что сейчас в Postgres: test с amount 999, без test2.

ОРКЕСТРАЦИЯ (Airflow + dbt)

  docker compose --profile orchestration up -d
  Airflow: http://localhost:8080 (admin / admin). Новые DAG'и появляются выключенными — включи переключателем.

  DAG'и:
    raw_to_mart_pipeline     (@daily)  generate_raw_data -> dbt_run -> dbt_test
                                       (raw_orders -> stg_orders -> mart_daily_sales в Postgres -> тесты dbt)
    batch_pg_to_clickhouse   (@daily)  pg_to_minio -> minio_to_clickhouse (ветка 1, шаги 2-3)
    cdc_minio_to_clickhouse  (@hourly) minio_to_clickhouse_cdc -> check_current_state (ветка 2, шаг 5)
                                       стрим kafka_to_minio.py работает отдельно (ветка 2, шаг 2),
                                       для CDC нужен профиль streaming

  Все Spark-задачи используют пул "spark" с 1 слотом (создаётся в airflow-init),
  поэтому два Spark-драйвера одновременно не запустятся. Проверить: Admin -> Pools.

Ручной запуск без Airflow:
  docker exec spark python /home/jovyan/scripts/generate_raw_data.py
  docker exec dbt dbt run
  docker exec dbt dbt test     # unique / not_null / accepted_values + тесты из dbt/tests
