АКТИВАЦИЯ SUPERSET

1. Подними Superset (ClickHouse и Postgres входят в ядро стека):
     docker compose --profile bi up -d

2. Инициализируй Superset (один раз; порядок важен — на пустой базе create-admin без db upgrade упадёт):
     docker exec superset superset db upgrade
     docker exec superset superset fab create-admin --username admin --firstname Admin --lastname User --email admin@admin.com --password admin
     docker exec superset superset init

3. Открой http://localhost:8088 и войди как admin / admin.

===============================================

ПОДКЛЮЧЕНИЕ БАЗ: Settings -> Database Connections -> + Database

Важно: в поле Host пиши имя контейнера (clickhouse, postgres-src), а не localhost —
Superset работает в своём контейнере, и localhost для него — он сам.

ClickHouse (выбрать ClickHouse Connect):
  Host: clickhouse   Port: 8123   Database: default   Username: default   Password: (пусто)
  или SQLAlchemy URI:
  clickhousedb://default:@clickhouse:8123/default

PostgreSQL (здесь витрина dbt mart_daily_sales):
  Host: postgres-src   Port: 5432   Database: mydb   Username: postgres   Password: postgres
  или SQLAlchemy URI:
  postgresql://postgres:postgres@postgres-src:5432/mydb
